## Guardrails applied

- No font binaries, logos, brand marks, illustrations or photography in the output.
- Component recipes are **re-authored** against the token variables — never a paste of the
  target's compiled CSS. Verified by n-gram overlap against `capture/static/*.css`.
- Token names retained (`kumo`, `cf-`) because `usageMode: internal`. **If this is ever made
  user-facing, re-run with `usageMode: shipping`** — that forces `namingStrategy: remap` plus an
  accent-hue divergence for trade-dress safety.
